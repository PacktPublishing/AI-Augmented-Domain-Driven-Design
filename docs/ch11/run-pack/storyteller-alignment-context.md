# Storyteller alignment context

## Workflow goal

Turn accepted Stock facts into concrete scenarios without resolving unsupported
policy.

## Accepted material

- accepted Storyteller input: `accepted-facts`
- Stock walkthrough as supporting evidence

## Approved terms

- Stock
- Sales
- set aside
- hold
- earmark

A new term may be proposed because the autonomy policy permits it. Repetition
does not make that term accepted.

## Unresolved

- ES-17

`ES-17` preserves incompatible short-quantity practices. Andrea rejects a request
when the full quantity is unavailable. Nadia sets aside what is available. No
accepted policy chooses between those practices.

## Prohibited decisions

- short-quantity-policy
- retry-owner
- hold-duration-policy

The orchestrator may assemble this context. It may not synthesize or normalize it.
